# Audios de démo (personne 3)

Dépose ici les phrases enregistrées au calme, une par fichier, au format `.m4a` (iPhone/Android) ou `.webm`.

Le fichier `phrases.json` liste ce que l'écran propose dans « Écouter un exemple » :

- `file` : le nom exact du fichier audio dans ce dossier
- `label` : ce que le jury lit sur le bouton
- `text` : la phrase dite, pour la transcription de référence

L'écran n'affiche que les entrées dont le fichier existe vraiment. Ces audios servent à la vidéo et à la démo devant le jury, à la place du micro dans une salle bruyante. Ils sont commités dans le dépôt (petits fichiers), contrairement aux 20 phrases de test dans `data/test/phrases/`.
